# Product name and compatibility

The product is **SonaFolio**, repository **sonafolio**, and CLI **atot**. Chinese is the default website/handbook; the top header opens English versions of the same pages.

Old identifiers remain in data paths/formats, credentials, internal builds, and historical research. They are not separate products or current support claims.

Audio2TextLibrary, Audio2TextCli, Swift targets, and generated Audio2Text.xcodeproj are intentional compatibility identities. Existing users need no branding-only data/package migration.
