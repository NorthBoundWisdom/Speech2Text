# 产品名与兼容名称

产品名 **SonaFolio**，GitHub 仓库 **sonafolio**，CLI 暂时保留 `atot`。官网和中文手册是默认用户入口。

旧名称保留在已有数据格式、目录、凭据身份、内部构建模块与历史实验中。它们不是另一个产品，也不是旧版本平台能力的当前承诺。

例如 `Audio2TextLibrary`、`Audio2TextCli`、Swift target 和生成的 `Audio2Text.xcodeproj` 是兼容身份。已有用户无需为了品牌变更迁移数据或重命名包。
