The site follows the [Ravo handbook](https://northboundwisdom.github.io/Ravo/) structure, using MkDocs
Material for English search, color schemes, mobile navigation, and build provenance. Source behavior
may be ahead of packages; each release describes its own capabilities.

Website source is in `website/`. Strict builds and link checks run before Pages deployment. Generated
output lives in `build/website/` and is not committed.
