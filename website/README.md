# SonaFolio 官网源码

[官网与用户手册](https://northboundwisdom.github.io/sonafolio/)使用 MkDocs Material，
参考 [Ravo 用户手册](https://northboundwisdom.github.io/Ravo/)的文档组织与 Pages 部署方式。
SonaFolio 的页面、样式与构建 hook 是本仓库维护的源码。

用户页在 `docs/`，主题配置在 `mkdocs.yml`，构建结果在仓库 `build/website/`。
首页中的节目内容是明确标注的布局示意，不是真实用户资料库或准确率证据。

[本地预览、验证与 Pages 部署](../doc/WEBSITE.md)

维护用户页面时，说明当前真实可用的功能、操作和数据边界。安装包和源码基线可能不同，
下载功能以各版本 release 说明为准。没有正式 release 时引导用户从源码开始。
